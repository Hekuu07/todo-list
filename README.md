📌 О проекте

To-Do List — учебный проект, разработанный с использованием HTML, CSS и JavaScript.

Приложение позволяет создавать задачи, отслеживать их выполнение, удалять ненужные задачи и сохранять данные между посещениями сайта.

✨ Основные возможности

➕ Добавление новых задач.

⌨️ Добавление задач нажатием клавиши Enter.

✅ Отметка выполненных задач нажатием на чекбокс или текст задачи.

🗑️ Удаление задач.

🔍 Фильтрация: все, активные и выполненные задачи.

💾 Автоматическое сохранение задач в LocalStorage.

📊 Счётчик выполненных и оставшихся задач.

📝 Сообщение при пустом списке.

📱 Адаптивный интерфейс для мобильных устройств.

🛠️ Технологии

HTML5 — структура приложения.

CSS3 — стилизация и адаптивный дизайн.

JavaScript (Vanilla JS) — логика приложения.

LocalStorage — локальное сохранение данных.

Google Fonts (Manrope) — типографика.

Git и GitHub — контроль версий и хранение проекта.

GitHub Pages — публикация приложения.

🚀 Запуск проекта локально

Склонируйте репозиторий:

git clone https://github.com/Hekuu07/todo-list.git

Откройте папку проекта:

cd todo-list

Откройте файл index.html в браузере.

💾 Хранение данных

Для сохранения задач используется браузерный LocalStorage.

Данные остаются доступными после обновления страницы и повторного открытия сайта в том же браузере.
